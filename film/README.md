# Two Strangers Who Were Never Meant to Meet — concept test

Assets for an animated short (motion-comic style), kept apart from the Lippan Studio app.

- `characters/` — character sheets. `*_v2.png` (GPT Image 2.5) are the approved looks; `*_v1.png` are discarded Gemini tests.
- `frames/` — test stills, named by shot number from the script. GPT Image 2.5 frames are the chosen style.
- `demo/motion_test.mp4` — 10-second silent test of slow push-ins and a crossfade, rendered with ffmpeg.

The script and shot list live in the Claude Docs document of the same title.
